## What "verified" means here

"Verified" means confirmed through a web fetch tool running outside this container: the tool loaded the page or endpoint at the reported URL and saw a closings list or an explicit empty state. Search results, GitHub copies of old pages and other people's scraper code only tell us where a URL came from. They do not verify it. Every endpoint in this report gets a direct check once the container can reach it, and nothing reaches the map before that check passes.

After round 4, 123 endpoints are verified, and every one is a Gray Media S3 GSync export. Round 4 added none. Three of them held real rows on 2026-09-25 (WSAZ, KWCH and WITN), and a round-4 fetch about 02:20 UTC saw the same rows. The rest returned the same explicit empty export, which proves the endpoint exists and parses but not that the station still writes to it. No station closings page is verified, and no endpoint on any other platform is. Each verified record in `sources.json` has a `verification_scope` field that says exactly what was seen.

Separately, seven Allen Media counters returned an explicit zero. They are recorded as verified count feeds. A counter holds a number and a link, not school names, so it can say whether anything is closed in a market but cannot put a school on the map. Count feeds never count as school-list sources.

Counting rules:

- A station counts once, however many lanes reported it. Evidence from each lane is merged into its how_found text.
- unverified_stations per state counts live leads (stations, aggregators, state systems and vendor feeds with a documented current URL) whose states list includes that state. Multi-state assignments often come from market geography, not from inspecting a list.
- Pointer records (a station that only links to another source), count-only feeds, URL patterns without a station, historical-only records and refuted records are kept in the stations array but not counted as leads.
- Reach estimates count schools in the Snowlight directory (pipeline/out/internal/directory/schools.parquet, NCES 2024-25 public and 2023-24 private, continental US) within 60 miles of each lead's market city (Census 2025 Gazetteer place centroid). Statewide systems count every school in their state. This is a planning proxy for how many schools an adapter could plausibly cover, not a measure of what any list contains.
- verified_stations per state counts stations whose school-list endpoint is verified (rounds 2 to 4: all are Gray S3 exports). A multi-state station counts in every state it lists; secondary states for the new Gray stations come from market geography (background knowledge).

## Gray GSync exports: the first working source

Every Gray station can be checked at `https://s3.amazonaws.com/grayfilestore-{call lowercase}/closingsData/closings_{CALL}.json`. The pattern comes from one public source, matt-kruse/qcweatherwatch.com index.html line 176 (the KWQC key). Every other key was built from it and then fetched. A missing key inside an existing bucket returns 403 (grayfilestore-kwqc/.../closings_NOPE.json, closings_XXXX.json; grayfilestore-wkyt/.../closings_WAVE.json; grayfilestore-kolo/.../closings_ZZZZ.json). A made-up bucket returns 404 (grayfilestore-zzzz, grayfilestore-zzzq). Bucket roots return 403, so nothing can be listed. Robots: for crawler purposes the robots.txt that governs the path-style URLs is https://s3.amazonaws.com/robots.txt (round 4 correction); S3 reads that path as a bucket named 'robots.txt' and returns HTTP 403. The virtual-host form grayfilestore-kwch.s3.amazonaws.com/robots.txt also returns 403. Under RFC 9309 a 4xx robots response means the file is unavailable and crawling is unrestricted, so robots exclusion is unlikely to explain any missing Wayback captures.

What the rows teach the parser:

- Items live in `record`. The empty form has no `record` key at all. `locations` holds title-case state names, not items, and `run_date` is always empty.
- `forced_county_name` holds the state in capitals; the county is in `county_name1`, with or without the word 'County'. `forced_category_name` reads 'Schools' at two stations and 'OH' at WSAZ, so it cannot be used as a filter.
- `forced_status_name` is free text with the weekday built in. 'Alert' is not a closure (KWCH's row is a bus-route change for muddy roads), so it needs its own class.
- Rows are per building (River Valley High and Middle School) and include non-K-12 organizations filed as 'Schools' (Pamlico Community College). Match every row to the NCES directory before it reaches the map.
- `expiration` has no time zone. KWCH's row expiring at 23:30 was still served at 20:37 and 21:37 CDT, which fits station-local time; neither fetch shows expired rows being served. The parser should apply `expiration` itself. `updated` is a date only, so posting latency cannot be read from the file.
- The rec_ids (398986 at KWCH, 398994-398996 at WSAZ, 398997-398999 at WITN) look like one shared sequence, so a school posted to two stations probably gets two rec_ids. Deduplicate on normalized name plus zip code.
- The rows came from a model's reading of each file, not raw bytes. Replace the fixtures with raw downloads from the runner's first poll, and record Last-Modified and ETag, which the fetch tool could not show.

How to read the ranking:

- Gray GSync comes first in the recommended order and TEGNA second; both are likely blockers, so both are build-but-hold. Gray covers about 41% of directory schools on its own, every one of its 123 leads is verified, and it is the only platform with observed rows. Build it now against the S3 exports (small JSON files on s3.amazonaws.com, not on station hosts), use the seven real rows as fixtures, keep the Arc gsync-closings path as a fallback (and do not assume it is on the page's own host), and hold production polling and publication until Gray's verbatim terms are read from the runner and Gray has given written permission if they need it.
- With no terms question at all, the order starts with the FOX O&O WorldNow closings iframe and the Cox Media Group Arc XP closing-list widget, and together the clean adapters reach only about 36% of directory schools, none of it verified. That is why the terms work now matters as much as the engineering.
- Nexstar alone would reach about 43% of directory schools, more than any other adapter. Nexstar now owns TEGNA, and its terms cover 'Affiliates', so one written permission request to Nexstar should cover Nexstar, TEGNA and possibly the Emergency Closing Center. Gray, Hearst and Scripps each need their own request. These requests are the most valuable non-engineering tasks. Move each platform to the front of the queue on the day its permission arrives.
- Statewide official systems (Delaware and West Virginia's WVEIS) rank low on new schools because TV stations already cover those states, but they are the cleanest sources and cheap to build. Build them early as reference data for checking the TV adapters.
- The proxy ignores how many schools each station actually lists. The first real measurements come from polling the Gray exports through a winter event and from the Wayback backfill.
